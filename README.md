# 🚀 Express System Metrics API

A lightweight Node.js & Express.js REST API service that exposes basic system runtime information, memory status, and uptime metrics via JSON endpoints.

## 🛠️ Features
- 🟢 **Status Endpoint (`/api/status`):** Checks uptime and API health.
- 📊 **Metrics Endpoint (`/api/metrics`):** Provides platform info, CPU cores, and RAM utilization.
- ⚡ **Minimal & Fast:** Built with core Node.js modules and Express.

## 🧰 Tech Stack
- **Runtime:** Node.js
- **Framework:** Express.js

## 📦 Setup & Execution

1. Clone the repository:
git clone https://github.com/westrox1337/express-metrics-api.git
cd express-metrics-api

2. Install dependencies:
npm install

3. Run the server:
npm start
